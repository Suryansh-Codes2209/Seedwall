# Seedwall Live (web) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add looping, seed-driven 3D/animated WebGL2 wallpapers to the Seedwall site, with still and loop-video export and a chromeless `/play` route for the Mac app.

**Architecture:** A `LiveScene` reuses the generator param schema and carries a GLSL ES 3.00 fragment shader. A small WebGL2 player maps params to uniforms automatically, drives time only through a loop phase, and exports stills and loops. Pages under `/live` reuse `ParamsPanel` and `DevicePicker`. Posters are generated by a headless-Chrome script that also compiles every shader.

**Tech Stack:** Next 16 (App Router), React 19, TypeScript 7, WebGL2/GLSL ES 3.00, MediaRecorder, vitest 5, playwright-core (dev only, uses the installed Chrome).

**Spec:** `docs/superpowers/specs/2026-11-24-live-wallpapers-design.md`

## Global Constraints
- No new runtime dependencies. `playwright-core` is a devDependency only.
- Scenes use time only through `uPhase`. No `uTime` or `iTime` appears anywhere in `src/live/scenes/`.
- Every scene has ≥4 presets with unique ids, a `seed` param of kind `seed`, a `speed` param, and `loopSeconds` between 8 and 60.
- Default fps is 30. Site render scale is `min(devicePixelRatio, 2)`. `/play` defaults to `scale=0.66`.
- `prefers-reduced-motion: reduce` → show the poster or one frame, and never start the RAF loop.
- Read `node_modules/next/dist/docs/` before adding routes. Existing tests, seed snapshots and still exports must stay green: `npx tsc --noEmit && npm test`.
- Copy uses the site's neutral tone. No mention of Wallpaper Engine anywhere on the site.

## Review Focus
1. **WebGL2 missing or context lost** (old Safari, GPU reset): the page shows the poster plus the line "This browser can't play live wallpapers. Here's a still.", and doesn't crash. Test: Task 2, `player falls back when getContext returns null`.
2. **Exporting at phone size 1179×2556 or 6K desktop:** keep the canvas within `MAX_TEXTURE_SIZE`/`MAX_RENDERBUFFER_SIZE`, scaling down if needed and saying so. Test: Task 5, `clampExportSize`.
3. **The tab is hidden mid-recording:** `recordLoop` rejects with `"Recording stopped: tab was hidden"` and leaves no half file. Test: Task 5.
4. **Bad URL state** (unknown preset, garbage `x`, out-of-range seed): falls back to defaults the way `decodeState` does. Test: Task 4, `decodeLiveState`.
5. **Hovering many cards fast on `/live`:** only one WebGL context ever exists. Test: Task 6, `LiveGrid uses one shared player`.

### Task 2: GLSL prelude and WebGL2 player

**Files:**
- Create: `src/live/glsl/prelude.ts` (exports `PRELUDE: string` and `buildFragment(scene: AnyLiveScene): string`), `src/live/player.ts`, `src/live/loop.ts`
- Test: `tests/live-player.test.ts`

**Interfaces:**
- Consumes: `paramUniforms`, `AnyLiveScene` (Task 1).
- Produces:
  - `phaseAt(elapsedMs: number, loopSeconds: number, speed: number): number`. Returns a value in [0,1). `speed` picks the effective loop from `[2, 1.5, 1, 0.75, 0.5]` multipliers of `loopSeconds`, so the loop length stays a whole multiple.
  - `shouldDraw(nowMs: number, lastMs: number, fps: number): boolean`
  - `smoothMouse(prev: [number,number], target: [number,number], dtMs: number): [number,number]`. Exponential, half-life 120 ms.
  - `createLivePlayer(canvas: HTMLCanvasElement, scene: AnyLiveScene, params: Params, opts?: { fps?: 30|60; scale?: number; mouse?: boolean; reducedMotion?: boolean }): LivePlayer | null`. It returns `null` when WebGL2 is unavailable or the shader fails to compile, and logs the info log via `console.error`.
  - `interface LivePlayer { start(): void; stop(): void; setParams(p: Params): void; setMouse(x: number, y: number): void; renderFrame(phase: number): void; readonly gl: WebGL2RenderingContext; dispose(): void }`
- The prelude declares `uniform vec2 uRes; uniform float uPhase, uLoop, uSeed; uniform vec2 uMouse;`, defines `TAU`, `hash21`, `noise`, `fbm(vec2,int)`, `sdSphere`, `sdBox`, `smin`, `softShadow`, `calcNormal` (with a `map` forward declaration guarded by `#ifdef SW_RAYMARCH`), and a `main()` that calls `scene(uv)` and applies output gamma. `buildFragment` concatenates `#version 300 es`, precision, the declared `u_*` uniforms generated from the schema, `PRELUDE` and `scene.fragment`.

- [ ] **Step 1: Write failing tests:**
  - `phaseAt` wraps: `phaseAt(0,10,1)===0`, `phaseAt(5000,10,1)===0.5`, `phaseAt(10000,10,1)===0`, `phaseAt(5000,10,0.5)===0.25` (the loop gets 2× longer).
  - `shouldDraw(1000, 990, 30) === false`, `shouldDraw(1034, 1000, 30) === true`.
  - `smoothMouse([0,0],[1,1],120)` returns values close to `[0.5,0.5]` (±0.01).
  - `buildFragment` declares `uniform vec3 u_bg;` for a colour param and starts with `#version 300 es`.
  - `player falls back when getContext returns null`: give it a fake canvas whose `getContext` returns null, and `createLivePlayer` returns null.
- [ ] **Step 2:** Run `npx vitest run tests/live-player.test.ts`. Expected: FAIL.
- [ ] **Step 3:** Implement. The player draws one full-screen triangle and calls `requestAnimationFrame`. It listens for `visibilitychange` (stop when hidden, resume when visible) and `webglcontextlost` (stop, then emit a `"lost"` event on the canvas via `CustomEvent`). With `reducedMotion`, `start()` only calls `renderFrame(0)`.
- [ ] **Step 4:** Run the tests and `tsc`. Expected: PASS.
- [ ] **Step 5:** Commit: `feat(live): WebGL2 player with loop phase, fps cap and fallbacks`
